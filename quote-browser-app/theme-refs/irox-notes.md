## Site design notes
- Page background: white/very light gray.
- Header: huge orange "o·w·n·e·d" wordmark (dotted separators) on the right, with a
  mock dictionary definition of "owned" beneath it ("1. a. To have or possess as
  property: owns a chain of restaurants..."). See irox-header-strip.png.
- Nav links in orange/rust: news / latest / random / browse / top 100 / add / search /
  store / garden gnomes / uk mobiles / dvorak / login. Old Google search box below.
- Breadcrumb: "-> o·w·n·e·d > latest >" in orange.
- Layout: narrow empty left sidebar (light gray box), quote cards on the right.
- Quote cards: very light gray boxes with thin gray borders; header "#4003 - 0 + [x]"
  in orange/rust; body text dark, plain font.
