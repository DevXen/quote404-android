# QDB.MIT.edu — theme reference notes

## Source capture
- Wayback Machine capture of `http://qdb.mit.edu/`, timestamp **20120220124500** (Feb 20, 2012).
- Structural stylesheet `res/themes/theme2/css/default.css` recovered from capture
  **20100610204716**; color stylesheet `res/themes/theme2/css/styles/stdefault.css`
  ("Chirpy! Default") from capture **20100610210233**.
- The PNGs in this folder are **reconstructed renders** of the archived HTML/CSS
  (rendered with WeasyPrint from the genuine archived files), not native browser
  screenshots. Layout and colors are faithful to the archived stylesheets; minor
  rendering differences vs. a period browser are possible.

## Background
- Page background is plain white/very light. Content sits in a centered column.

## Branding / header
- Rounded maroon header bar (`#993333`) spanning the content width, with the site
  title **"qdb.mit.edu"** in gray (`#999999`), italic serif-ish styling, left-aligned
  inside the bar. The bar has a subtle lighter edge/highlight giving it a
  pill/rounded look.
- No image logo — the wordmark is text on the maroon bar.

## Navigation
- Horizontal nav directly under the header bar, items separated by slashes:
  `/ Home / Browse / Random / Top / Bottom / Search / Tags / Stats / Submit /`
- Nav links are dark/plain text; section titles on the page ("MIT's Funny Quotes",
  "Latest News") are large black headings.
- A bold purple **"SUBMIT YOUR FUNNY QUOTES!!"** link sits in the left column.

## Quote headers
- Quote number links are purple (`#4D0099`).
- Voting/sample links: upvote green (`#009900`), downvote dark red (`#990000`).
- Quote header rows get a pale orange hover/highlight (`#FFE9C9`-ish / `#F0D0A0` tones).

## Cards / body
- Quote bodies are nearly white (`#FFFCEC` / `#FFF3F3` tints) with thin borders.
- The homepage's "Sample Quotes" box is pale orange (`#FFE9C9`).
- A bordered disclaimer box sits lower on the page; footer carries an
  "EDUbash Consortium" badge image and a "Powered by Chirpy! v0.4" credit.

## Fonts
- Verdana, Arial, Helvetica, sans-serif throughout. Quote text is plain
  proportional sans (not monospace).

## Approximate palette
- Maroon `#993333` (header bar)
- Gray `#999999` (title text on bar)
- Purple `#4D0099` (links)
- Green `#009900` (upvote / positive accents)
- Dark red `#990000` (downvote / negative accents)
- Pale orange `#FFE9C9` (quote header highlight / sample box)
- Near-white `#FFFCEC` (quote body)
