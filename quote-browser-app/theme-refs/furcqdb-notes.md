# furcqdb / Mandaliet (Furcadia Quotes!) theme reference (from Clint's screenshot, 2026-09-15)

Source: quote-browser-app/theme-refs/furcqdb-original.png (full page screenshot)

## Clint's directive
- Use this as the theme for the Mandaliet.com/furcqdb database.

## Site design notes
- Page background: black.
- Title: "FURCADIA QUOTES!" in bright blue, right-aligned.
- Nav bar: black with thin orange border; links in orange/peach:
  Home / Show quotes: Latest (positive only), Highest scoring, Random / Search / Links / Submit a quote.
- "Next 50 ->" pager bar, same bordered style, right-aligned.
- Quote header line: white text "Quote #", quote number in orange, "Current score: N"
  with orange + / - vote links, "Total votes: N Submitted: YYYY-MM-DD HH:MM:SS" in gray.
- Quote body: tan/beige card (~#D8CFC0-ish; sample from screenshot) with thin orange
  border, dark text, plain (non-monospace) font.
